# Инструмент проверки совместимости моделей с Barracuda

Данный инструмент позволяет проверить совместимость ONNX-моделей с Unity Barracuda без необходимости запуска полной сцены AR. 

## Для чего нужен инструмент?

- Проверка совместимости экспортированных моделей DeepLabV3 с Barracuda
- Определение ключевых параметров модели (размеры входа/выхода, поддерживаемые бэкенды)
- Быстрая проверка всех моделей в проекте или из указанной директории
- Генерация отчетов о совместимости

## Как использовать инструмент

### Вариант 1: Использование через редактор Unity

1. Откройте инструмент через меню: **Remalux AR > Model Compatibility Checker**
2. Добавьте модели для проверки одним из способов:
   - Нажмите **Find All Models** для автоматического поиска всех моделей в проекте
   - Перетащите модели напрямую в поле "Add Model"
   - Укажите директорию с ONNX-файлами и нажмите **Scan Directory for ONNX Models**
3. Нажмите кнопку **Check Compatibility** для запуска проверки
4. Просмотрите результаты в окне редактора
5. При необходимости нажмите **Export Report** для сохранения отчета в файл

### Вариант 2: Использование в режиме запуска

1. Создайте новую сцену
2. Добавьте на сцену GameObject с компонентом `BarracudaModelChecker`
3. Настройте компонент, добавив модели для проверки
4. Добавьте компонент `ModelCheckerScene` для более удобного интерфейса
5. Запустите сцену для проведения проверки

### Вариант 3: Использование из кода

```csharp
using WallDetection;
using Unity.Barracuda;

// Проверка отдельной модели
public void CheckModel(NNModel model)
{
    string errorMessage;
    bool isCompatible = BarracudaModelChecker.CheckModelCompatibilityStatic(model, out errorMessage);
    
    if (isCompatible)
    {
        Debug.Log($"Модель {model.name} совместима с Barracuda");
    }
    else
    {
        Debug.LogError($"Модель {model.name} несовместима с Barracuda: {errorMessage}");
    }
}
```

## Структура отчета о совместимости

Отчет о совместимости содержит следующую информацию для каждой модели:

- Имя модели и путь к файлу
- Статус совместимости (Да/Нет)
- Сообщение об ошибке (если есть)
- Размеры входного тензора (ширина x высота)
- Размеры выходного тензора (ширина x высота x каналы)
- Имена входных и выходных узлов
- Размер модели в байтах
- Поддерживаемые бэкенды (CPU, GPU и др.)

## Частые проблемы и решения

### Ошибка "Failed to parse ONNX file"

**Возможные причины:**
- Несовместимость версии ONNX с Barracuda
- Повреждение файла модели
- Использование неподдерживаемых операторов

**Решение:**
- Убедитесь, что модель экспортирована с использованием opset 11 (рекомендуется для совместимости с Barracuda)
- Попробуйте пересоздать модель с использованием скрипта `export_mobilenet.py` с параметром `--opset_version 11`

### Ошибка "No worker available for the model"

**Возможные причины:**
- Модель содержит операторы, не поддерживаемые ни одним из доступных бэкендов

**Решение:**
- Упростите модель, удалив неподдерживаемые слои или заменив их на эквивалентные
- Проверьте, какие бэкенды доступны в вашей сборке Unity

### Ошибка "Input tensor dimensions don't match"

**Возможные причины:**
- Неправильная форма входного тензора

**Решение:**
- Убедитесь, что в DeepLabDecoder задан правильный размер входа, соответствующий модели

## Требования для экспорта совместимых моделей

При экспорте моделей DeepLabV3 с помощью скриптов в `model_export` обратите внимание на следующие ключевые параметры:

1. **Версия ONNX opset**: Используйте версию 11 для максимальной совместимости с Barracuda:
   ```bash
   python export_mobilenet.py --opset_version 11
   ```

2. **Размеры входного изображения**: Укажите размер, соответствующий настройкам в DeepLabDecoder:
   ```bash
   python export_mobilenet.py --input_size 320
   ```

3. **Выходная директория**: Рекомендуется сохранять модели в директорию `Assets/Models`:
   ```bash
   python export_mobilenet.py --output_dir ../../Models
   ```

## Интеграция с проектом

Для интеграции инструмента с основным проектом рекомендуется:

1. Добавить проверку совместимости при загрузке модели в DeepLabDecoder
2. Реализовать автоматическую загрузку резервной модели в случае несовместимости
3. Добавить подробную диагностическую информацию при возникновении проблем

## Расширение функциональности

Инструмент можно расширить следующими возможностями:

- Профилирование производительности моделей

- Сравнение разных версий одной и той же модели
- Автоматическая конвертация несовместимых моделей
