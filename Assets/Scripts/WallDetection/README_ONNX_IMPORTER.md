# Инструмент конвертации ONNX моделей в формат NNModel

Инструмент `OnnxImporter` предназначен для автоматизированной конвертации ONNX-моделей в формат NNModel, используемый Unity Barracuda. Он позволяет проводить пакетную обработку нескольких моделей с различными настройками и проверкой совместимости.

## Основные возможности

- Пакетная конвертация нескольких ONNX-моделей в формат NNModel
- Автоматическая проверка совместимости с Barracuda
- Возможность создания тестовых префабов для моделей
- Поддержка различных настроек импорта
- Детальные отчеты о результатах конвертации

## Запуск инструмента

1. Откройте инструмент через меню: **Remalux AR > ONNX to NNModel Converter**
2. Укажите исходную директорию с ONNX-моделями
3. Укажите целевую директорию для сохранения NNModel-файлов
4. Настройте дополнительные параметры
5. Нажмите кнопку "Сканировать директорию" для поиска моделей
6. Нажмите кнопку "Конвертировать все" для начала процесса конвертации

## Настройки инструмента

### Основные настройки

- **Директория с ONNX**: путь к директории, содержащей ONNX-модели для конвертации
- **Директория NNModel**: путь внутри проекта Unity для сохранения конвертированных моделей

### Дополнительные настройки

- **Фильтр файлов**: маска для поиска ONNX-файлов (по умолчанию "*.onnx")
- **Рекурсивный поиск**: включение поиска в поддиректориях
- **Перезаписывать существующие**: перезаписывать ли существующие модели
- **Удалять ONNX после импорта**: удалять ли исходные ONNX-файлы после успешной конвертации
- **Проверять совместимость**: проверять ли совместимость модели с Barracuda после конвертации
- **Создавать префабы моделей**: создавать ли тестовые префабы с компонентом DeepLabDecoder
- **Расположение данных в памяти**: выбор формата хранения данных (ChannelsLast или ChannelsFirst)
- **Уровень логирования**: детализация логирования процесса конвертации (0-3)

## Процесс конвертации

1. Инструмент сканирует указанную директорию и находит все ONNX-файлы
2. Каждый файл копируется в проект Unity (если это необходимо)
3. Unity автоматически конвертирует ONNX в NNModel при импорте
4. Если автоматическая конвертация не удалась, используется программный метод конвертации
5. Проверяется совместимость полученной модели с Barracuda
6. При необходимости создается тестовый префаб для модели
7. Результаты конвертации отображаются в интерфейсе

## Примеры использования

### Базовый сценарий

1. Экспорт моделей DeepLabV3 с помощью скриптов в директорию вне проекта Unity
2. Запуск инструмента и выбор этой директории
3. Выбор директории "Assets/Models" в качестве целевой
4. Конвертация всех моделей с проверкой совместимости
5. Использование конвертированных моделей в DeepLabDecoder

### Продвинутый сценарий

1. Настройка различных параметров экспорта для серии моделей DeepLabV3
2. Создание отдельных директорий для разных вариантов моделей
3. Конвертация моделей с созданием тестовых префабов
4. Автоматическая проверка совместимости и сбор информации о размерах и характеристиках моделей
5. Выбор оптимальной модели на основе анализа результатов

## Решение проблем

### Модель не конвертируется автоматически

Если модель не конвертируется автоматически, инструмент попытается выполнить программную конвертацию. Если проблема сохраняется:

1. Убедитесь, что ONNX-файл корректен и соответствует спецификации
2. Проверьте, что версия ONNX opset совместима с Barracuda (рекомендуется opset 11)
3. Увеличьте уровень логирования до 3 для получения подробной информации о процессе конвертации

### Модель конвертируется, но несовместима с Barracuda

Если модель успешно конвертируется, но признается несовместимой:

1. Проверьте сообщение об ошибке для выяснения конкретной причины
2. Экспортируйте модель с другими параметрами, учитывая ограничения Barracuda
3. Убедитесь, что модель использует только операции, поддерживаемые Barracuda

### Проблемы с производительностью при пакетной конвертации

При конвертации большого количества моделей:

1. Обработка моделей происходит последовательно с небольшими паузами
2. Для больших моделей процесс может занять значительное время
3. Не закрывайте Unity до завершения процесса конвертации
4. Следите за использованием памяти при конвертации большого количества моделей

## Интеграция с рабочим процессом

Инструмент `OnnxImporter` разработан для интеграции с общим рабочим процессом разработки:

1. Экспорт моделей из Python-скриптов
2. Пакетная конвертация в Unity с проверкой совместимости
3. Проверка и сравнение моделей с помощью `BarracudaModelChecker`
4. Тестирование производительности с использованием `DeepLabModelTester`
5. Выбор оптимальной модели для использования в приложении

## Дополнительная информация

- При создании префабов автоматически настраивается компонент DeepLabDecoder с указанием на конвертированную модель
- Можно конвертировать индивидуальные модели, нажав кнопку "Конвертировать" напротив каждой модели в списке
- Инструмент сохраняет относительную структуру директорий при конвертации моделей
- Результаты конвертации включают информацию о размере модели и поддерживаемых backend'ах
