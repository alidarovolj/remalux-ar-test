# Руководство по тестированию и сравнению моделей DeepLabV3

Это руководство описывает полный процесс экспорта, тестирования и сравнения моделей DeepLabV3 (ResNet и MobileNet) для выбора оптимальной конфигурации под ваши требования.

## Предварительные требования

1. Unity 2020.3 или новее с установленными пакетами:
   - AR Foundation
   - Barracuda
   - XR Plugin Management

2. Python 3.7 или новее с необходимыми пакетами:
   ```
   pip install torch torchvision onnx numpy matplotlib pillow
   ```

3. Базовое знание Unity и работы с командной строкой

## Шаг 1: Экспорт моделей DeepLabV3

### Вариант 1: Использование скрипта автоматизации (рекомендуется)

Запустите скрипт полного цикла тестирования, который автоматически экспортирует модели, анализирует результаты и создает отчеты:

#### На Windows:
```
cd Assets/Scripts/WallDetection
run_full_model_test.bat
```

#### На macOS/Linux:
```
cd Assets/Scripts/WallDetection
chmod +x run_full_model_test.sh
./run_full_model_test.sh
```

### Вариант 2: Ручной экспорт моделей

1. Перейдите в директорию `Assets/Scripts/WallDetection/model_export`
2. Запустите скрипт экспорта MobileNet с разными разрешениями:
   ```
   python export_mobilenet.py --input_size 224 --output_dir ../../models
   python export_mobilenet.py --input_size 320 --output_dir ../../models
   python export_mobilenet.py --input_size 512 --output_dir ../../models
   ```

## Шаг 2: Импорт моделей в Unity

1. Откройте проект в Unity
2. Найдите экспортированные модели в директории `Assets/models`
3. Убедитесь, что Unity успешно импортировал файлы ONNX

## Шаг 3: Настройка сцены для тестирования

1. Создайте новую тестовую сцену или откройте существующую
2. Добавьте на сцену следующие компоненты:
   - AR Session
   - AR Session Origin с AR Camera
   - Canvas для UI элементов
3. Добавьте на AR Camera компонент `DeepLabDecoder`
4. Добавьте пустой GameObject и прикрепите к нему компоненты:
   - `DeepLabModelTester` - для сравнения моделей
   - `WallDetectionTester` - для тестирования распознавания стен
5. Настройте UI элементы согласно инструкциям в `TestInstructions.md`

## Шаг 4: Настройка тестеров моделей

### Настройка DeepLabModelTester:

1. В инспекторе Unity настройте `DeepLabModelTester`:
   - Добавьте экспортированные модели в список `Models` (как ResNet, так и MobileNet)
   - Задайте количество итераций тестирования (рекомендуется 50+)
   - Включите опцию `Save Results To File`

### Настройка WallDetectionTester:

1. В инспекторе Unity настройте `WallDetectionTester`:
   - Свяжите с DeepLabDecoder
   - Настройте UI элементы для отображения результатов
   - Включите автоматический захват кадров и сохранение результатов

## Шаг 5: Проведение тестирования

### Тестирование моделей с DeepLabModelTester

1. Запустите сцену в Unity Editor или на устройстве
2. Нажмите кнопку "Start Benchmark" в интерфейсе DeepLabModelTester
3. Дождитесь завершения тестирования для всех моделей
4. Результаты будут сохранены в файл `ModelBenchmarkResults.json`

### Тестирование распознавания стен с WallDetectionTester

1. Для каждой модели:
   - Выберите модель в DeepLabDecoder
   - Запустите сцену и направьте камеру на стены
   - Соберите не менее 10-20 образцов для анализа
   - Результаты будут сохранены в директории `WallDetectionTests`

## Шаг 6: Анализ результатов

### Вариант 1: Автоматический анализ

Запустите скрипты анализа для обработки собранных результатов:

```
cd Assets/Scripts/WallDetection/analysis_tools
python analyze_test_results.py --dir ../../WallDetectionTests --report
python compare_models.py --dir ../../WallDetectionTests
```

### Вариант 2: Ручной анализ в Unity

1. Просмотрите результаты тестирования в интерфейсе DeepLabModelTester
2. Сравните метрики производительности:
   - Среднее время обработки
   - FPS (кадры в секунду)
   - Использование памяти

## Шаг 7: Интерпретация результатов

Откройте сгенерированные отчеты:

1. **HTML-отчет анализа результатов**: `WallDetectionTests/wall_detection_report.html`
   - Содержит статистику по всем тестам
   - Визуализирует распределение времени обработки и качества маски

2. **Отчет по сравнению моделей**: `WallDetectionTests/model_comparisons/model_comparison.html`
   - Сравнивает результаты разных моделей на одних и тех же изображениях
   - Включает метрики производительности и графики

## Шаг 8: Выбор оптимальной конфигурации

Используйте полученные результаты для выбора оптимальной конфигурации:

1. **Мобильные устройства с ограниченной производительностью**:
   - MobileNet с разрешением 224x224 или 320x320
   - Более низкие значения интервала обработки (выше FPS)

2. **Устройства средней производительности**:
   - MobileNet с разрешением 320x320 или 512x512
   - Или ResNet с разрешением 224x224 для лучшего качества

3. **Высокопроизводительные устройства**:
   - ResNet с разрешением 320x320 или 512x512
   - Более высокое качество распознавания стен

## Шаг 9: Интеграция в основное приложение

После выбора оптимальной конфигурации:

1. Обновите DeepLabDecoder в основном приложении с выбранной моделью
2. Настройте параметры согласно результатам тестирования:
   - Размер входного изображения
   - Интервал обработки кадров
   - Параметры для условий освещения

## Советы по тестированию

1. **Разнообразные условия освещения**:
   - Протестируйте в условиях яркого освещения
   - Протестируйте в условиях низкого освещения
   - Протестируйте в условиях смешанного освещения

2. **Различные стены и поверхности**:
   - Одноцветные стены
   - Текстурированные поверхности
   - Стены с объектами (картины, мебель)

3. **Разные устройства**:
   - По возможности протестируйте на разных моделях устройств
   - Сравните производительность на iOS и Android

## Устранение неполадок

1. **Ошибки экспорта моделей**:
   - Убедитесь, что установлены все необходимые пакеты Python
   - Проверьте версию ONNX (рекомендуется opset 11)

2. **Проблемы с производительностью**:
   - Уменьшите разрешение входного изображения
   - Увеличьте интервал обработки кадров
   - Проверьте использование GPU/CPU в настройках

3. **Проблемы с качеством распознавания**:
   - Настройте параметры для низкого освещения
   - Оптимизируйте постобработку маски
   - Попробуйте другую модель или разрешение
