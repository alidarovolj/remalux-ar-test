# Инструкция по тестированию системы распознавания стен

## Настройка тестовой сцены

1. Создайте новую сцену Unity или откройте существующую тестовую сцену
2. Добавьте на сцену следующие компоненты:
   - AR Session
   - AR Session Origin с AR Camera
   - Canvas для UI элементов
3. Добавьте на AR Camera компонент `DeepLabDecoder`
4. Добавьте пустой GameObject и прикрепите к нему компонент `WallDetectionTester`
5. Создайте необходимые UI элементы:
   - RawImage для отображения оригинального изображения
   - RawImage для отображения маски стены
   - RawImage для отображения результата
   - Кнопки для захвата кадра и сохранения результатов
   - Текстовые поля для отображения статистики

## Настройка WallDetectionTester

1. В инспекторе Unity настройте ссылки на созданные UI элементы
2. Установите параметры тестирования:
   - `autoCapture`: автоматический захват кадров (true/false)
   - `captureInterval`: интервал между захватами (в секундах)
   - `autoSaveResults`: автоматическое сохранение результатов (true/false)
   - `savePath`: путь для сохранения результатов (по умолчанию "WallDetectionTests")
   - `maxStatsSamples`: максимальное количество сохраняемых образцов для статистики

## Настройка DeepLabDecoder

1. Сконфигурируйте параметры DeepLabDecoder:
   - Выберите `modelAsset` - ONNX или NNModel файл вашей модели
   - Установите `resolutionPreset` для тестирования разных разрешений
   - Настройте параметры для различных условий освещения:
     - `autoAdjustLighting`: автоматическая адаптация к условиям освещения
     - `lowLightBoost`: степень усиления в условиях слабого освещения
     - `lowLightThreshold`: порог для определения слабого освещения
     - `contrastEnhancement`: степень улучшения контраста
   - Настройте параметры производительности:
     - `processingInterval`: интервал между обработкой кадров
     - `showPerformanceMetrics`: отображение метрик производительности

## Проведение тестирования

1. Запустите сцену в Unity Editor или на устройстве
2. Если `autoCapture` выключен, нажимайте кнопку захвата кадра, направляя камеру на стены
3. Наблюдайте за результатами в соответствующих RawImage
4. Во время тестирования изменяйте параметры DeepLabDecoder для сравнения результатов
5. Сохраните результаты, нажав соответствующую кнопку (если `autoSaveResults` выключен)

## Анализ результатов

1. После завершения тестирования проверьте папку с сохраненными результатами
2. Для каждого тестового случая вы найдете:
   - Оригинальное изображение
   - Маску стены
   - Финальный результат
   - JSON-файл с метриками производительности и статистикой
3. Сравните результаты для разных параметров и условий:
   - Различные разрешения входного изображения
   - Различные условия освещения
   - Различные настройки постобработки

## Рекомендации по тестированию

1. Тестируйте в различных условиях освещения:
   - Яркое естественное освещение
   - Искусственное освещение
   - Слабое освещение
   - Смешанное освещение

2. Тестируйте на разных типах стен:
   - Однотонные стены
   - Стены с текстурой
   - Стены с контрастными элементами (картины, мебель)

3. Тестируйте разные углы и расстояния:
   - Фронтальный вид на стену
   - Боковой вид под углом
   - Различные расстояния до стены

4. Для сравнения моделей используйте `DeepLabModelTester`:
   - Добавьте несколько моделей с разными архитектурами
   - Запустите тестирование по одним и тем же сценам
   - Сравните производительность и качество распознавания

## Оптимизация параметров

На основе результатов тестирования определите оптимальные параметры для:

1. Баланса качества и производительности:
   - Оптимальное разрешение входного изображения
   - Оптимальный интервал обработки кадров

2. Улучшения качества распознавания:
   - Настройки постобработки маски стены
   - Параметры адаптации к условиям освещения

## Рекомендации для интеграции в основное приложение

После завершения тестирования и оптимизации параметров:

1. Перенесите оптимальные настройки в основное приложение
2. Создайте профили настроек для различных условий и устройств
3. Реализуйте автоматическую адаптацию параметров в зависимости от:
   - Производительности устройства
   - Условий освещения
   - Требований пользователя к качеству/производительности
