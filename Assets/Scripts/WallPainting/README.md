# Система покраски стен с использованием AR + DeepLabv3 + OpenCV

Данная система позволяет определять стены через камеру мобильного устройства с помощью нейросети DeepLabv3 и "покрасить" их в виртуальном AR-пространстве.

## Обзор технологий

В системе используются следующие технологии:

- **Unity AR Foundation** — обеспечивает AR-функциональность, трекинг камеры, определение плоскостей
- **DeepLabv3** — нейронная сеть для семантической сегментации, выделяет стены на изображении
- **OpenCV** — используется для постобработки сегментации и улучшения детекции стен
- **Unity Barracuda** — для запуска нейросети прямо на устройстве

## Распределение обязанностей между компонентами

### DeepLabv3 (нейросеть)
- Выявляет на кадрах камеры пиксели, соответствующие стенам
- Генерирует маску сегментации, где стены имеют определенную метку
- Запускается на устройстве с помощью Barracuda (оптимизированная модель)

### OpenCV
- Обрабатывает маску сегментации — удаляет шум, заполняет дыры
- Позволяет более точно определить границы стен

### Unity AR Foundation
- Трекинг камеры и позиционирование в пространстве
- Определение 3D-пространства и плоскостей
- Размещение виртуальных объектов (покрашенных стен) в AR
- Сохранение якорей для стабильного отображения покрашенных зон

## Структура системы

### Основные компоненты

1. **DeepLabDecoder** — обрабатывает результаты сегментации DeepLabv3
   - Получает кадры с камеры
   - Выполняет инференс через Barracuda
   - Генерирует маску стен

2. **WallPainter** — управляет покраской стен
   - Преобразует 2D-маску в 3D-объекты в AR-пространстве
   - Создает якоря для сохранения положения покрашенных стен
   - Обеспечивает взаимодействие с пользователем

3. **ARWorldMapController** — управляет сохранением и загрузкой AR-сцены
   - Позволяет сохранять положение покрашенных стен между сеансами
   - Восстанавливает сцену при возвращении в комнату

4. **WallPaintingUIController** — управляет пользовательским интерфейсом
   - Позволяет выбирать цвета покраски
   - Настраивать параметры работы
   - Управлять сохранением и загрузкой

### Дополнительные компоненты

- **PaintedWall** — компонент для отображения покрашенной стены
- **OnnxConverter** (редактор) — конвертирует ONNX модели в формат Barracuda
- **export_deeplabv3_onnx.py** — экспортирует DeepLabv3 в правильном формате ONNX

## Как использовать систему

### Настройка проекта

1. Запустите Python-скрипт `export_deeplabv3_onnx.py` для экспорта моделей в формат ONNX
2. Импортируйте модели в Unity и конвертируйте их в формат NNModel с помощью OnnxConverter
3. Убедитесь, что в проект установлены пакеты:
   - AR Foundation
   - ARKit XR Plugin (iOS) или ARCore XR Plugin (Android)
   - Unity Barracuda
   - OpenCV для Unity (опционально)

### Компоненты сцены

1. Настройте AR Session и AR Session Origin
2. Добавьте компоненты DeepLabDecoder, WallPainter, ARWorldMapController
3. Настройте UI с использованием WallPaintingUIController

### Использование приложения

1. При запуске приложения происходит инициализация AR и загрузка нейросети
2. Система автоматически определяет стены через камеру
3. Пользователь может:
   - Нажать на экран для покраски стены в выбранный цвет
   - Изменить цвет покраски
   - Включить/выключить автоматическую покраску
   - Сохранить и загрузить сцену

## Особенности и преимущества системы

- Работает на больших расстояниях (не ограничена 1-3 метрами как обычные AR плоскости)
- Сохраняет покрашенные стены между сеансами
- Игнорирует объекты на стенах (картины, мебель) благодаря постобработке
- Работает в реальном времени на мобильных устройствах
- Поддерживает iOS и Android

## Требования к оборудованию

- iPhone с iOS 11+ (рекомендуется iOS 13+) или Android 7.0+ с поддержкой ARCore
- Для лучшей производительности рекомендуется использовать устройства с NPU/GPU
- Для сохранения карты мира на iOS требуется iPhone с A12 Bionic или новее

## Ограничения и известные проблемы

- Качество сегментации зависит от освещения сцены
- На слабых устройствах возможны задержки при обработке
- Для некоторых функций требуются современные устройства
