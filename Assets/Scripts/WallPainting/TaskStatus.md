## Инструменты профилирования и анализа производительности

Для оптимизации и выбора наилучшей конфигурации DeepLabV3 были созданы следующие инструменты:

### Улучшенные скрипты экспорта и тестирования моделей
- Обновленный скрипт `export_mobilenet.py` с расширенной функциональностью:
  - Поддержка как MobileNetV3, так и ResNet50 бэкбонов
  - Оптимизация ONNX моделей для улучшения производительности
  - Валидация моделей с использованием тестовых изображений
  - Визуализация и сохранение результатов сегментации
  - Расширенная диагностика и обработка ошибок
- Вспомогательный скрипт `test_export.py` для быстрой проверки процесса экспорта
- Пакетные скрипты для автоматического экспорта моделей различных размеров
- Система загрузки и тестирования на образцах изображений

### Инструменты анализа моделей
- Скрипт `analyze_models.py` для комплексного анализа экспортированных моделей:
  - Извлечение характеристик модели (размер файла, количество параметров)
  - Подсчет операций и анализ графа вычислений
  - Визуализация сравнительных характеристик в виде графиков
  - Генерация HTML-отчетов с рекомендациями по выбору модели
  - Сопоставление моделей с различными размерами и архитектурами
- Скрипты `analyze_models.sh` и `analyze_models.bat` для быстрого запуска анализа
- Возможность экспорта данных в CSV для дальнейшего анализа

### PerformanceProfiler
- Мониторинг ключевых показателей производительности в реальном времени:
  - FPS (кадры в секунду)
  - Использование CPU
  - Потребление памяти
  - Время обработки кадра
- Сохранение логов в формате CSV для последующего анализа
- Визуализация показателей через Unity UI

### Анализатор логов производительности
- Python-скрипт `analyze_performance_logs.py` для:
  - Обработки и анализа логов производительности
  - Генерации сравнительных графиков
  - Расчета важных метрик (средние значения, пики, распределения)
  - Создания HTML-отчета с рекомендациями
- Поддержка сравнения нескольких моделей с различными параметрами
- Визуализация зависимости производительности от разрешения входных данных

### Автоматизированный процесс тестирования

- Генерация полных отчетов о характеристиках моделей и их производительности
