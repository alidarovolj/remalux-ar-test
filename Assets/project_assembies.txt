## Troubleshooting
If you encounter missing assembly references, follow these steps:
1. Open Unity and go to Tools > Reload Packages
2. After Unity recompiles, use Tools > Fix Missing Assembly References
3. If issues persist, use Tools > Recompile All Assemblies

For manual fixes, ensure all assembly definition files include the appropriate references from the list above.
