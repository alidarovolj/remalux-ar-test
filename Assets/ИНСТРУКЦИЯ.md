# Инструкция по использованию проекта Remalux AR

## 1. Настройка и запуск проекта

### Первый запуск

1. Откройте проект в Unity 2022.3 или новее
2. После открытия проекта появятся ошибки компиляции - это нормально для первого запуска
3. В верхнем меню выберите **Remalux → Fix All Project Issues**
4. Дождитесь завершения процесса и **перезапустите Unity**
5. После перезапуска проект должен скомпилироваться без ошибок

### Проверка статуса проекта

Если возникают проблемы, вы можете проверить текущий статус проекта:

1. Выберите в меню **Remalux → Project Status**
2. Проверьте выведенную в консоли информацию о состоянии проекта
3. Следуйте рекомендациям, если они указаны

## 2. Экспорт и работа с моделями DeepLabV3

### Подготовка окружения для экспорта моделей

#### macOS (включая Apple Silicon)

1. Откройте терминал
2. Перейдите в директорию `Assets/Scripts/WallDetection/model_export`
3. Запустите скрипт установки зависимостей:
   ```bash
   chmod +x install_arm64_deps.sh
   ./install_arm64_deps.sh
   ```
4. После установки вы можете использовать скрипт экспорта:
   ```bash
   python export_arm64.py --model mobilenet --size 320 --quantize
   ```

#### Windows

1. Откройте командную строку
2. Перейдите в директорию `Assets\Scripts\WallDetection\model_export`
3. Запустите скрипт установки зависимостей:
   ```cmd
   install_arm64_deps.bat
   ```
4. После установки вы можете использовать скрипт экспорта:
   ```cmd
   python export_arm64.py --model mobilenet --size 320 --quantize
   ```

### Параметры экспорта моделей

Скрипт `export_arm64.py` поддерживает следующие параметры:

- `--model` - тип модели: `mobilenet` или `resnet50`
- `--size` - размер входного изображения (по умолчанию 320)
- `--output` - директория для сохранения экспортированных моделей
- `--quantize` - применить квантизацию модели для ускорения
- `--test` - тестировать модель после экспорта

Пример:
```bash
python export_arm64.py --model resnet50 --size 512 --quantize --test
```

## 3. Тестирование распознавания стен

1. Откройте сцену `Assets/Scenes/TestScene.unity`
2. Нажмите кнопку Play в редакторе
3. Используйте интерфейс тестирования для:
   - Загрузки тестовых изображений
   - Настройки параметров распознавания
   - Сохранения результатов и статистики

### Использование инструмента WallDetectionTester

1. Выберите объект с компонентом `WallDetectionTester` в сцене
2. В инспекторе настройте:
   - Исходные изображения для тестирования
   - Опции автоматического захвата кадров
   - Путь для сохранения результатов

### Пакетное тестирование моделей

1. Используйте класс `TestSceneGenerator` для создания серии тестов
2. В инспекторе настройте:
   - Набор тестовых изображений
   - Список моделей для тестирования
   - Параметры сохранения результатов

## 4. Настройка распознавания

### Основные параметры

1. Выберите объект с компонентом `SettingsManager` в сцене
2. Настройте параметры в следующих группах:
   - **Разрешение** - качество и размер обработки
   - **Производительность** - баланс между скоростью и точностью
   - **Освещение** - параметры коррекции освещения
   - **Цвета стен** - настройка палитры и стилей окраски

### Настройка для мобильных устройств

Для оптимальной работы на мобильных устройствах:

1. Уменьшите значение `Resolution Quality` до `Medium` или `Low`
2. Включите опцию `Use Inference Optimization`
3. Используйте модель на основе MobileNet вместо ResNet

## 5. Сборка и тестирование на устройстве

### Сборка для iOS (включая Apple Silicon)

1. Откройте **Build Settings** (File → Build Settings)
2. Выберите платформу iOS
3. Нажмите кнопку **Switch Platform**
4. Перед сборкой запустите **Remalux → Fix All Project Issues**
5. Нажмите **Build** или **Build and Run**

### Сборка для Android

1. Откройте **Build Settings** (File → Build Settings)
2. Выберите платформу Android
3. Нажмите кнопку **Switch Platform**
4. Настройте минимальные требования (API Level 24+)
5. Нажмите **Build** или **Build and Run**

## 6. Устранение неполадок

Если возникают проблемы с проектом, воспользуйтесь специальными инструментами:

### Проблемы с Barracuda

1. Выберите **Tools → Fix Barracuda Dependency**
2. Перезапустите Unity

### Проблемы с экспортом моделей

Обратитесь к документации в файле:
`Assets/Scripts/WallDetection/model_export/README-TROUBLESHOOTING.md`

### Общие проблемы с компиляцией

1. Закройте Unity
2. Удалите папки `Library` и `Temp`
3. Перезапустите Unity
4. Выполните **Remalux → Fix All Project Issues**
