# Remalux AR - Система распознавания и покраски стен в дополненной реальности

Remalux AR - это мобильное приложение на базе Unity для распознавания и виртуальной покраски стен с использованием дополненной реальности (AR) и компьютерного зрения.

## Основные функции

- 🔍 **Распознавание стен** с использованием нейронной сети DeepLabV3
- 🎨 **Виртуальная покраска стен** с возможностью выбора цветов и текстур
- 📱 **Поддержка AR** на мобильных устройствах через ARFoundation
- 📊 **Инструменты анализа и тестирования** моделей сегментации
- ⚙️ **Гибкая система настроек** для оптимизации под разные устройства
- 🔄 **Адаптивная обработка видео** с учетом условий освещения

## Архитектура проекта

Проект построен на основе модульной архитектуры с четким разделением функциональности:

### Основные модули

- **WallDetection**: Модули для обнаружения стен с использованием DeepLabV3
  - `DeepLabDecoder.cs` - Основной компонент для обработки результатов сегментации
  - `DeepLabModelTester.cs` - Инструмент для сравнения различных моделей DeepLabV3
  - `WallDetectionTester.cs` - Инструмент для тестирования и анализа распознавания стен
  - `TestScenePrefab.cs` - Префаб для быстрого создания тестовых сцен

- **WallPainting**: Модули для покраски и текстурирования стен
  - `WallPainter.cs` - Компонент для нанесения цвета/текстуры на стену
  - `WallData.cs` - Структура данных для сохранения информации о стенах
  - `WallDataList.cs` - Контейнер для коллекции данных о стенах

- **Settings**: Система настроек приложения
  - `SettingsManager.cs` - Центральный менеджер настроек
  - `SettingsUI.cs` - Пользовательский интерфейс для настроек
  - `ColorPickerUI.cs` - Интерфейс выбора цвета для стен

### Технологический стек

- **Unity 2022.3** и выше
- **AR Foundation** для поддержки дополненной реальности
- **Barracuda** для запуска нейросетевых моделей на устройстве
- **DeepLabV3** для семантической сегментации изображений
- **TextMeshPro** для UI элементов

## Использование

### Требования

- Unity 2022.3 или выше
- AR Foundation Package
- Barracuda Package
- Мобильное устройство с поддержкой ARCore (Android) или ARKit (iOS)

### Установка и запуск

1. Клонируйте репозиторий
2. Откройте проект в Unity
3. Установите необходимые пакеты через Package Manager
4. Запустите сцену `Assets/Scenes/MainScene.unity`

### Тестирование моделей

Для сравнения различных конфигураций моделей DeepLabV3:

1. Откройте сцену `Assets/Scenes/ModelTestScene.unity`
2. Добавьте модели в компонент `DeepLabModelTester`
3. Запустите сцену и нажмите на кнопку "Run Tests"

## Настройка

Приложение предоставляет гибкие настройки для оптимизации под различные устройства:

### Настройки распознавания

- **Разрешение входного изображения**: От 224x224 до 768x768 и пользовательские размеры
- **Интервал обработки**: Частота обновления сегментации (от каждого кадра до 1 раза в секунду)
- **Порог уверенности**: Настройка чувствительности алгоритма сегментации

### Настройки освещения

- **Автоматическая адаптация**: Включение/отключение автоматической настройки под условия освещения
- **Усиление при низком освещении**: Корректировка яркости при недостаточном освещении
- **Порог низкого освещения**: Уровень яркости, при котором включается усиление
- **Корректировка контраста**: Настройка контрастности для улучшения распознавания

## Производительность

Проект оптимизирован для работы на мобильных устройствах с различными характеристиками:
